# 使用说明

本文件是随安装包附带的快速使用指南。完整排错与实现细节见同目录下的 `README.md` 与 `docs/how-it-works.md`。

---

## 一、这个包是什么

本安装包里同时包含两部分，缺一不可：

| 内容 | 位置 | 作用 |
| --- | --- | --- |
| **Chrome 扩展** | `extension/` 文件夹 | 读取视频页、显示下载面板 |
| **本地助手** | `host/` 里的 `bili-host` 可执行文件 | 实际下载与合成 MP4 |

必须先运行安装脚本把「本地助手」注册到浏览器，**再**加载 `extension` 文件夹。顺序反了也能用，但加载完扩展后必须重启一次浏览器。

> 不需要安装 Python、FFmpeg 或任何运行库，也不需要管理员 / root 权限。

---

## 二、安装（共 3 步）

### Windows

**第 1 步：解压**

右键压缩包 → **全部解压到当前文件夹**。

> ⚠️ 不要在压缩软件的窗口里直接双击 `install.bat`。那样文件处于只读状态，安装会失败。

解压后应该看到：

```
bili-downloader-2.0.0-windows\
├── install.bat          ← 待会双击这个
├── uninstall.bat
├── README.md            ← 完整说明
├── docs\
│   ├── usage.md         ← 本文件
│   └── how-it-works.md  ← 运行原理
├── extension\           ← 待会要加载这个文件夹
└── host\
    └── bili-host.exe
```

**第 2 步：双击 `install.bat`**

会弹出一个黑色窗口，几秒内完成，看到类似下面的输出即为成功：

```
[1/3] 本地助手已就绪: C:\Users\你\AppData\Local\BiliDownloader\bili-host.exe
[2/3] 已生成清单: ...\com.opencode.bili_downloader.json
      扩展 ID: khkbfeoekeinbdgbicojpgfidfihfffc
[3/3] 本地助手注册完成。
      - Chrome: 已注册
      - Edge: 已注册
```

按任意键关闭窗口即可。

脚本只做三件事：复制一个 exe 到你的用户目录、写一个 json 清单、在 `HKCU`（当前用户）下加注册表项。如果杀毒软件弹窗，选择「允许」。

**第 3 步：加载扩展**

1. 地址栏打开 `chrome://extensions/`（Edge 用 `edge://extensions/`）
2. 打开右上角 **「开发者模式」**
3. 点 **「加载已解压的扩展程序」**
4. 选择本目录下的 **`extension`** 文件夹（不是它的上级目录）
5. 工具栏出现粉色 **B** 图标

**然后完全退出浏览器再重新打开一次**，让新注册的本地助手生效。

---

### Linux

**第 1 步：解压**

```bash
tar -xzf bili-downloader-2.0.0-linux-x64.tar.gz
cd bili-downloader-2.0.0-linux
```

**第 2 步：运行安装脚本**

```bash
./install.sh
```

没有执行权限时：

```bash
chmod +x install.sh && ./install.sh
```

只想先看它改什么、不做实际改动：

```bash
./install.sh --check
```

**第 3 步：加载扩展**

与 Windows 完全相同：打开 `chrome://extensions/` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择本目录的 `extension` 文件夹。

**然后完全退出浏览器再重新打开一次。**

> Snap / Flatpak 版 Chromium 有沙箱限制，读不到 `~/.local` 这类隐藏目录。`install.sh` 会自动把助手和清单放到沙箱可访问的位置，你不需要做额外配置。

## 三、下载一个视频

1. 打开任意 B 站视频页，例如 `https://www.bilibili.com/video/BV1xx411c7mD`
2. 点击工具栏的粉色 **B** 图标
3. 面板会自动读出标题与可用清晰度

面板各项含义：

| 项目 | 说明 |
| --- | --- |
| **视频清晰度 / 编码** | 默认选 1080P 的 AVC（兼容性最好）。AVC 排在最前，HEVC / AV1 在下面 |
| **音频质量** | 默认选码率最高的音轨 |
| **保存位置** | 默认是系统下载目录，可点「选择…」或直接改 |
| **保留中间文件** | 默认关闭。开启后保留下载的 `.m4s`，便于排查问题 |
| **分 P 选择** | 仅多 P 视频出现 |

4. 点 **「下载并合成 MP4」**
5. 完成后点「打开所在文件夹」查看成品

下载过程中**可以关掉面板**，任务在后台继续；工具栏图标上会显示进度百分比。

**快捷键**：`Alt+Shift+B` 打开面板（冲突时可在 `chrome://extensions/shortcuts` 修改）。

## 四、面板上的状态说明

| 显示 | 含义 | 需要做什么 |
| --- | --- | --- |
| 解析下载地址 | 正在探测文件大小和各 CDN 镜像 | 等待 |
| 下载视频流 / 音频流 | 分片并行下载中，显示速度与剩余时间 | 等待 |
| 合成 MP4 | 内置引擎重排文件，不重新编码 | 等待，通常 1~2 秒 |
| 下载完成 | 已校验通过 | 可打开所在文件夹 |
| 排队中 | 已有任务在跑，本任务会自动开始 | 等待 |
| **下载已中断** | 浏览器回收了扩展后台页面 | 点「继续下载」续传 |
| 下载失败 | 见红框内的具体原因 | 见下方排错表 |

## 五、常见问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「本地助手未安装或未注册」 | 未运行安装脚本，或安装后没重启浏览器 | 运行 `install.bat` / `./install.sh`，然后**完全退出浏览器重启** |
| 提示「扩展 ID 不一致」 | 扩展被改动过 | 重新运行安装脚本，它会自动识别 |
| 点图标提示「请先打开 B 站视频页」 | 当前标签不是视频页 | 先打开一个 B 站视频 |
| 下载完成后「再点没反应」 | 1.x 的旧问题 | 2.0 已修复，重新加载扩展即可 |
| 速度慢 / 中途变慢 | CDN 对单连接限速 | 默认已用 8 连接；换清晰度或避开网络高峰 |
| 下载中途失败 | 网络中断，或浏览器回收了后台 | 重新点下载会**从断点续传**，不会从头来 |
| 提示「媒体地址已过期（HTTP 403）」 | 播放地址有时效签名 | 扩展会自动刷新一次并续传；仍失败则刷新视频页重试 |
| 只有 480P | 未登录，或该清晰度需要大会员 | 在浏览器里正常登录 B 站后重试 |
| 合成失败 / 播放器打不开 | 极少见 | 勾选「保留中间文件」后重试，便于定位 |
| Windows：`install.bat` 一闪而过 | 在压缩包里直接双击了 | 先完整解压再运行 |
| Windows：找不到 `bili-host.exe` | 被杀毒软件删除 | 加白名单后重新解压 |
| Linux：一直提示助手不可用 | Snap / Flatpak 沙箱 | 用新版 `install.sh` 重装；它会自动处理 |

## 六、卸载

**Windows**：双击 `uninstall.bat`，然后在 `chrome://extensions/` 移除「Bili 下载器」。

**Linux**：

```bash
./uninstall.sh
```

然后在 `chrome://extensions/` 移除扩展。

---

## 七、注意事项

- 清晰度取决于**你的账号**：未登录一般最高 480P，登录后 1080P，大会员才有更高清晰度 / 4K / HDR。
- 不支持直播、付费课程与 DRM 保护内容；部分番剧受版权与地区限制。
- 请遵守 B 站服务条款与视频作者的授权，**仅保存你有权保存的内容**。
- 全部处理都在本地完成，不经过任何第三方服务器；扩展不会读取或上传你的 Cookie。
