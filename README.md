# Bili 下载器

一个 Chrome / Chromium 扩展，用来下载 B 站网页视频，并直接合成为**普通 MP4**。
下载、合成全部在本机完成，不上传任何数据。

**不需要 Python，不需要 FFmpeg，不需要配置 PATH，也不需要管理员 / root 权限。**

## 功能

- 在任意 `https://www.bilibili.com/video/BV...` 视频页点击扩展图标即可下载。
- 自动使用页面登录态，列出**你的账号有权限的**清晰度（360P ~ 4K / HDR）。
- 编码可选：默认 **AVC（H.264，兼容性最好）**，也支持 HEVC / AV1。
- 支持**分 P 视频**，面板里可直接切换。
- **8 连接并行下载**，多 CDN 镜像自动测速与故障切换。
- **断点续传**：连接断开、进程退出、浏览器回收后台页面，都能从已下载的分段继续。
- 下载默认保存到系统**下载目录**，可在面板里修改。
- 后台下载：关掉面板不影响任务；工具栏图标显示**下载进度百分比**，完成后显示 ✓。
- 可选保留 `.m4s` 中间文件；默认合成后自动清理。
- 完成后可在面板里直接「打开所在文件夹」。
- **交互式安装 / 卸载**：自动检测浏览器，列出每个浏览器会改动的文件，支持多选；
  发现旧版本文件时再次确认覆盖或取消。不需要任何命令行参数。

## 下载哪个包

| 你的系统 | 下载 |
| --- | --- |
| Windows 10 / 11（x64） | `bili-downloader-2.0.3-windows-x64.zip` |
| Linux x86_64 | `bili-downloader-2.0.3-linux-x64.tar.gz` |
| Linux ARM64 | `bili-downloader-2.0.3-linux-arm64.tar.gz` |

每个包都完整可用：里面同时包含扩展、对应架构的本地助手和说明文档。
如果你的机器是 32 位系统，本扩展不提供对应助手，请使用 64 位系统。

## Windows 安装

支持 Chrome、Chrome Beta/Dev、Edge、Brave、Chromium、Vivaldi、Opera、Yandex。

### 1. 解压

下载 `bili-downloader-2.0.3-windows-x64.zip`，右键 → **全部解压到当前文件夹**。

> 一定要先解压。不要在压缩软件窗口里直接双击 `install.bat`，那样安装会失败。

解压后目录如下：

```
bili-downloader-2.0.3-windows-x64\
├── 先看这里.txt
├── install.bat          ← 双击这个
├── install.ps1          ← 安装流程（由 bat 调用）
├── uninstall.bat        ← 双击卸载
├── uninstall.ps1
├── README.md
├── docs\
├── extension\
└── host\
    └── bili-host.exe
```

### 2. 双击 `install.bat`

脚本是**交互式**的，会依次让你确认：

1. 自动检测本机已安装的 Chromium 系浏览器，并列出每个浏览器安装后会被改动的
   文件与注册表项；
2. 输入编号**多选**要安装的浏览器（`all` 全选，`1 3` 或 `1,3` 选多个）；
3. 确认后如果发现目标位置已有旧文件，会再次询问：
   **覆盖 / 跳过有旧文件的浏览器 / 取消**；
4. 安装完成后，逐个浏览器显示「加载扩展」的具体步骤。

不需要任何命令行参数，也不需要管理员权限。如果杀毒软件弹窗，选择「允许」。

### 3. 加载扩展

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）。
2. 打开右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择解压目录里的 **`extension`** 文件夹（不是它的上级目录）。
5. 工具栏出现粉色 **B** 图标。

### 4. 重启浏览器

完全退出浏览器再打开一次，让新注册的本地助手生效。

## Linux 安装

支持 Chrome、Chrome Beta/Dev、Chromium、Brave、Edge、Vivaldi、Opera、Yandex，包括 Snap 和 Flatpak 版。

### 1. 解压

根据架构选择包：

```bash
# x86_64
tar -xzf bili-downloader-2.0.3-linux-x64.tar.gz
cd bili-downloader-2.0.3-linux-x64

# ARM64
tar -xzf bili-downloader-2.0.3-linux-arm64.tar.gz
cd bili-downloader-2.0.3-linux-arm64
```

### 2. 运行安装脚本

```bash
./install.sh
```

没有执行权限时：

```bash
chmod +x install.sh && ./install.sh
```

脚本会自动识别系统架构和浏览器，然后列出每个浏览器会改动的文件，让你
**多选**安装；如果目标目录里已有旧版本文件，会再次确认**覆盖 / 跳过 / 取消**。
脚本不需要任何命令行参数，也不需要 `sudo`。

Snap / Flatpak 版 Chromium 的沙箱读不到 `~/.local`，脚本会自动把助手装到它们能访问的目录，无需手动配置。

### 3. 加载扩展

1. 打开 `chrome://extensions/`。
2. 打开右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本目录下的 **`extension`** 文件夹。
5. 工具栏出现粉色 **B** 图标。

### 4. 重启浏览器

完全退出浏览器再打开一次，让本地助手注册生效。

## 使用

1. 打开任意 B 站视频页，例如 `https://www.bilibili.com/video/BV1xx411c7mD`。
2. 点击工具栏的粉色 **B** 图标。
3. 选择**清晰度 / 编码**和**音频**（默认已选好 AVC + 最佳音质）。
4. 多 P 视频可以在「分 P」里切换。
5. 需要改保存位置就点「选择」，或直接改输入框。
6. 点 **「下载 MP4」**。
7. 完成后点「打开所在文件夹」查看成品。

下载过程中可以关掉面板，任务会继续在后台运行，工具栏图标显示**下载进度百分比**。
切到其它网页后再点图标，也会直接显示当前下载进度，不会报「请先打开视频页」。

**快捷键**：`Alt+Shift+B` 打开面板。与其他扩展冲突时，可在 `chrome://extensions/shortcuts` 修改。

### 面板状态

| 显示 | 含义 | 需要做什么 |
| --- | --- | --- |
| 解析下载地址 | 正在探测文件大小和 CDN 镜像 | 等待 |
| 下载视频流 / 音频流 | 分片并行下载中 | 等待 |
| 合成 MP4 | 内置引擎重排文件，不重新编码 | 等待，通常 1~2 秒 |
| 已下载 | 已校验通过 | 点「打开所在文件夹」 |
| 排队中 | 前面的任务完成后自动开始 | 等待 |
| 下载已中断 | 浏览器回收了扩展后台页面 | 点「继续下载」续传 |
| 下载失败 | 红框内会显示具体原因 | 见下方常见问题 |

## 常见问题

**提示「本地助手未安装或未注册」**
先运行安装脚本（Windows 双击 `install.bat`，Linux 运行 `./install.sh`），然后完全退出浏览器再打开。
仍不行时，到 `chrome://extensions/` 确认扩展 ID 为 `khkbfeoekeinbdgbicojpgfidfihfffc`，再重新运行一次安装脚本。

**清晰度只有 480P**
清晰度取决于账号权限：未登录一般最高 480P，登录后 1080P，大会员才有 1080P+ / 4K / HDR。

**下载到一半失败，要从头再来吗**
不用。已完成的字节会保留，重新点下载即可从断点继续。
如果面板显示「下载已中断」，点「继续下载」即可。

**提示「媒体地址已过期（HTTP 403）」**
扩展会自动刷新一次播放地址并续传；仍失败时刷新视频页后重新下载。

**Windows 双击 `install.bat` 一闪而过**
通常是直接在压缩包里运行的。请先完整解压，再运行。

**支持 macOS 吗**
当前只发布 Windows 和 Linux 包。macOS 可以从源码构建，但没有安装向导。

## 卸载

Windows：双击 `uninstall.bat`。脚本同样是交互式的：先检测已注册的浏览器和残留文件，
让你多选要卸载的浏览器，确认后删除注册表项、清单和助手文件，最后提示你到浏览器里移除扩展。

Linux：

```bash
./uninstall.sh
```

同样会列出浏览器、标出哪些目录里还有安装文件，让你多选后确认卸载。
卸载完成后，到 `chrome://extensions/`（或对应浏览器的扩展管理页）移除「Bili 下载器」。

## 说明

- 下载能力取决于账号权限；不支持直播、付费课程、DRM 保护内容。
- 番剧受版权与地区限制时可能无法获取播放地址。
- HEVC / AV1 成品需要播放器支持对应编码；默认优先选 AVC。
- 页面脚本只在 B 站视频页运行，只调用 B 站自己的 API，不导出 Cookie。
- 请遵守哔哩哔哩用户协议与视频作者的授权，仅保存你有权保存的内容。
