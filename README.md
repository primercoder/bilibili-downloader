# Bili 下载器

一个 Chrome / Chromium 扩展，用来下载 B 站网页视频，并直接合成为**普通 MP4**。
下载、合成全部在本机完成，不上传任何数据。

**不需要 Python，不需要 FFmpeg，不需要配置 PATH，也不需要管理员 / root 权限。**

## 功能

- 在任意 `https://www.bilibili.com/video/BV...` 视频页点击扩展图标即可下载。
- 自动使用页面登录态，列出**你的账号有权限的**清晰度（360P ~ 4K / HDR）。
- 编码可选：默认 **AVC（H.264，兼容性最好）**，也支持 HEVC / AV1。
- 支持**分 P 视频**与**番剧 / 影视**；番剧可在面板里按「选集」切换。
- **8 连接并行下载**，多 CDN 镜像自动测速与故障切换。
- **断点续传**：连接断开、进程退出、浏览器回收后台页面，都能从已下载的分段继续。
- 下载默认保存到系统**下载目录**，可在面板里修改。
- 后台下载：关掉面板不影响任务；工具栏图标显示**下载进度百分比**，完成后显示 ✓。
- 可选保留 `.m4s` 中间文件；默认合成后自动清理。
- 完成后可在面板里直接「打开所在文件夹」。
- **本地 HTTP 助手**：监听 `127.0.0.1` 的本地端口，扩展自动发现并连接；
  不需要注册 Native Messaging，也不需要写浏览器清单或注册表。
- **托盘应用**：助手常驻系统托盘，图标颜色反映状态（空闲 / 下载 / 合成），
  菜单可打开下载文件夹、开关开机自启、退出。
- **双击即用**：Windows 上双击 `bili-host.exe` 即可，没有控制台窗口，不需要安装脚本。

## 本地助手如何连接

扩展不注册 Chrome Native Messaging，也不写浏览器清单或注册表。本地助手是独立的用户进程：

- 监听 `127.0.0.1` 的 `47821–47860`，自动选择空闲端口
- 扩展扫描端口，用 `GET /health` 识别助手
- 下载任务通过 `POST /jobs` 提交
- 进度通过 SSE `GET /events` 推送；连接建立或重连时先取一次 `/jobs` 快照
- 没有活动任务时断开 SSE，助手仍在后台继续下载

助手和扩展互不依赖启动顺序：助手先在托盘启动，扩展每次打开面板都会重新发现它。
Windows 不需要安装脚本，双击 `host\bili-host.exe` 即可；Linux 另附可选的 `install.sh`。

完整的下载逻辑、前后端交互、合成与校验等技术细节见 [TECH.md](TECH.md)。

## 下载哪个包

| 你的系统 | 下载 |
| --- | --- |
| Windows 10 / 11（x64） | `bili-downloader-2.3.0-windows-x64.zip` |
| Linux x86_64 | `bili-downloader-2.3.0-linux-x64.tar.gz` |
| Linux ARM64 | `bili-downloader-2.3.0-linux-arm64.tar.gz` |

每个包都完整可用：里面同时包含扩展、对应架构的本地助手和说明文档。
如果你的机器是 32 位系统，本扩展不提供对应助手，请使用 64 位系统。

## Windows 安装

支持 Chrome、Chrome Beta/Dev、Edge、Brave、Chromium、Vivaldi、Opera、Yandex。

### 1. 解压

下载 `bili-downloader-2.3.0-windows-x64.zip`，右键 → **全部解压到当前文件夹**。

> 一定要先解压，不要在压缩软件窗口里直接运行。

解压后目录如下：

```
bili-downloader-2.3.0-windows-x64\
├── README.md
├── extension\
└── host\
    └── bili-host.exe
```

### 2. 双击 `host\bili-host.exe`

就这样，没有安装脚本，也不需要命令行参数：

- 助手是一个**托盘程序**，双击后不会弹出黑色控制台窗口
- 它会在系统托盘区出现一个粉色 B 图标
- 扩展会自动找到它（本地端口 `47821–47860`）

如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

### 3. 开机自启（可选）

右键托盘图标 → 菜单里勾选 **「开机自启」**。它会在当前用户下写一个启动项，
不需要管理员权限；再次点击即取消。菜单项前面的对勾就是当前状态。

### 4. 加载扩展

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）。
2. 打开右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择解压目录里的 **`extension`** 文件夹（不是它的上级目录）。
5. 工具栏出现粉色 **B** 图标。

> 助手和扩展互不依赖启动顺序：先开哪个都行，扩展每次打开面板都会重新查找助手。

## Linux 安装

支持 Chrome、Chrome Beta/Dev、Chromium、Brave、Edge、Vivaldi、Opera、Yandex，包括 Snap 和 Flatpak 版。

### 1. 解压

根据架构选择包：

```bash
# x86_64
tar -xzf bili-downloader-2.3.0-linux-x64.tar.gz
cd bili-downloader-2.3.0-linux-x64

# ARM64
tar -xzf bili-downloader-2.3.0-linux-arm64.tar.gz
cd bili-downloader-2.3.0-linux-arm64
```

### 2. 运行助手

```bash
chmod +x host/bili-host-linux-*
./host/bili-host-linux-amd64      # ARM64 机器用 bili-host-linux-arm64
```

助手是托盘程序，运行后会在系统托盘区出现一个图标，同时监听本地端口。
不需要 `sudo`，不需要 systemd，也不会写任何浏览器配置。

如果你想安装到固定位置并开机自启，可以运行附带的脚本（可选）：

```bash
./install.sh    # 复制到 ~/.local/share/bili-downloader 并设置登录自启
```

### 3. 加载扩展

1. 打开 `chrome://extensions/`。
2. 打开右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本目录下的 **`extension`** 文件夹。
5. 工具栏出现粉色 **B** 图标。

> 托盘图标需要桌面环境的 StatusNotifierItem 支持（GNOME 需安装 AppIndicator 扩展）。
> 即使没有托盘图标，助手仍然照常工作，扩展可以正常下载。

## 使用

1. 打开任意 B 站视频页，例如 `https://www.bilibili.com/video/BV1xx411c7mD`。
2. 点击工具栏的粉色 **B** 图标。
3. 选择**清晰度 / 编码**和**音频**（默认已选好 AVC + 最佳音质）。
4. 多 P 视频可以在「分 P」里切换；番剧页面会在「选集」里列出有权限的剧集。
5. 需要改保存位置就点「选择」，或直接改输入框。
6. 点 **「下载 MP4」**。
7. 完成后点「打开所在文件夹」查看成品。

下载过程中可以关掉面板，任务会继续在后台运行，工具栏图标显示**下载进度百分比**。
切到其它网页后再点图标，也会直接显示当前下载进度，不会报「请先打开视频页」。

**快捷键**：`Alt+Shift+B` 打开面板。与其他扩展冲突时，可在 `chrome://extensions/shortcuts` 修改。

### 面板状态

| 显示 | 含义 | 需要做什么 |
| --- | --- | --- |
| 解析下载地址 | 正在探测文件大小和 CDN 镜像 | 等待 |
| 下载中 | 视频/音频分片并行下载中（进度为两条流的合计） | 等待 |
| 合并中 | 内置引擎重排文件并校验，不重新编码 | 等待，通常 1~2 秒 |
| 已下载 | 已校验通过 | 点「打开所在文件夹」 |
| 排队中 | 前面的任务完成后自动开始 | 等待 |
| 下载已中断 | 本地助手退出或连接中断 | 点「继续下载」续传 |
| 下载失败 | 红框内会显示具体原因 | 见下方常见问题 |

## 常见问题

**提示「本地助手未运行」**
Windows 双击 `host\bili-host.exe`；Linux 运行 `./host/bili-host-linux-amd64`。
助手启动后托盘区会出现图标。如果浏览器没有反应，到扩展管理页点一下「重新加载」。

**托盘图标没出现，但下载能用**
Linux 上的 GNOME 默认不显示 StatusNotifierItem，需要安装 AppIndicator 扩展。
Windows 上如果图标被折叠，点任务栏的「^」把它拖出来。

**Windows 双击 bili-host.exe 没有任何反应**
说明已有一个助手在运行（助手是单实例）。此时任务栏托盘区应该已经有图标；
如果确实没有，查看 `%TEMP%\bili-downloader-host.log`。

**清晰度只有 480P**
清晰度取决于账号权限：未登录一般最高 480P，登录后 1080P，大会员才有 1080P+ / 4K / HDR。

**下载到一半失败，要从头再来吗**
不用。已完成的字节会保留，重新点下载即可从断点继续。
如果面板显示「下载已中断」，点「继续下载」即可。

**提示「媒体地址已过期（HTTP 403）」**
扩展会自动刷新一次播放地址并续传；仍失败时刷新视频页后重新下载。

**支持 macOS 吗**
当前只发布 Windows 和 Linux 包。macOS 可以从源码构建，但没有安装向导。

## 卸载

1. 右键托盘图标 → **「退出」**。
2. 如果开过「开机自启」，先在菜单里取消它。
3. 删除解压出来的文件夹。
4. 到 `chrome://extensions/`（或对应浏览器的扩展管理页）移除「Bili 下载器」。

如果之前运行过脚本安装（Linux `./install.sh`），可以用 `./uninstall.sh` 清理
`~/.local/share/bili-downloader` 和自启动文件。

## 说明

- 下载能力取决于账号权限；不支持直播、付费课程、DRM 保护内容。
- 番剧受版权与地区限制时可能无法获取播放地址。
- HEVC / AV1 成品需要播放器支持对应编码；默认优先选 AVC。
- 页面脚本只在 B 站视频页运行，只调用 B 站自己的 API，不导出 Cookie。
- 请遵守哔哩哔哩用户协议与视频作者的授权，仅保存你有权保存的内容。
